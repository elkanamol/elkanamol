## 🚀 What I Do

I build deterministic embedded software for resource-constrained, connected devices. My focus is on turning low-level system constraints into robust, production-ready behavior:

- **System Architecture:** Active Object design patterns, lock-free data structures (MPSC ring buffers), static memory allocation, and MISRA C:2012 compliance.
- **Real-Time Firmware:** RTOS (Zephyr, FreeRTOS, RTEMS) and bare-metal architectures in C/C++.
- **Hardware Integration:** Board bring-up, low-level driver development, and sensor fusion.
- **Cellular & Wireless IoT:** LTE, 5G, NB-IoT, and NTN integration, managing complex AT command flows, MBIM, and QMI.
